# Apparel Demand & Order Forecasting Dashboard

This project is an interactive Power BI dashboard that I built to understand
how customer orders are distributed across products and different order
periods.

The dashboard focuses on order volume, backlog orders, current orders and
future demand. It also provides a view of customer demand, product-wise
demand, order value and demand forecasting across upcoming periods.

I built the report using Power BI, Power Query and DAX. The data was cleaned
and transformed in Power Query before being used for analysis and dashboard
visualization. I also created the required measures and calculations in DAX
to support the KPIs, demand analysis and forecasting views.

The report has two main pages. The first page provides an overall view of
apparel demand and order forecasting, while the second page provides a more
detailed view of the order load by product, including backlog and current
orders.

The main areas covered in the dashboard are:

- Total, current, backlog and future orders
- Customer-wise demand
- Product-wise demand
- Order value analysis
- Backlog and current order analysis
- Period-wise demand forecasting
- Interactive filtering by customer, product, category and due period

### Tools Used

Power BI | DAX | Power Query | Data Modeling | Excel

portfolio data.
